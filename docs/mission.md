# ミッション

| 達成段階 | 確認する成果 |
|---|---|
| Minimum | 放出・降下・着地判定、安全な着地、分離、必要な校正、展開、自律走行開始、地上局受信 |
| Full | 左右画像の取得・転送、センサー対応付け、視差・点群・自己位置、点群統合と可視化、実物との定量比較 |
| Extra | 観測状況と走破性を区別し、自動計画・経路伝送・機体追従・障害物回避。目標0.5 m以内は実測で評価し、内部判定と区別する |

状態遷移の検討順は起動 → 待機 → 降下 → 着地確認 → 分離 → 展開 → 走行準備 → 走行・観測 → 終了。異常時は安全停止または復旧に移る。単発の衝撃や高度変化だけで着地を確定しない。指令送信・受付・実行完了・失敗を追跡する。再起動後は機構やモジュールの実状態を確認する。

| Mission Mode | 走行再開条件 |
|---|---|
| BASIC | 撮影や地上局の計画に依存しない基本走行 |
| MAPPING | 静止撮影して画像の保持を確認。転送と処理は走行と並行 |
| MAPPING_WAIT | 地上局で左右画像の受信・保存を確認 |
| TERRAIN_NAV | 地形評価を経た有効な経路を確認 |

撮影前に静止を確認。未観測領域への無条件進入やTERRAIN_NAVからBASICへの無条件な縮退を行わない。競技時間20分は現行計画値。公式の停止要件と自動Uplinkの可否は確認待ち。

# 開発ロードマップ

| 時期 | 予定と依存 |
|---|---|
| 11月末 | シミュレーター・既存コード調査・環境・分担確認 |
| 12月上旬 | ハード仕様確認、CAN共同設計、初心者の環境確認 |
| 12月中旬 | Main・Camera・Drive単体、画像担当のステレオ初期検証 |
| 12月下旬 | CAN・TWELITE・Wi-Fi結合、地上局連携、VO・SLAM |
| 1月上旬〜中旬 | Minimum初期統合、Fullの一連の処理を実機または利用可能なデータで確認 |
| 1月中旬〜末 | 大学試験につき開発休止を基本とする。実日程は班内調整 |
| 2月以降 | 実機・屋外、故障復旧、地図精度、Extra、大会想定試験と最終調整 |

MinimumとFullは並行する。Extraの調査は早期に行い、結合は観測済み地形と経路通信の検証後。部品は11月末〜12月想定、基板完成日は未確認。実機利用開始までは既存機材・仮想入力を使う。担当ごとの着手項目は[要求](requirements.md)。

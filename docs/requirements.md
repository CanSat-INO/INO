# 担当と開発要求

| 担当 | 必須の開発領域 | 最初の作業 |
|---|---|---|
| 班長・地上局 | 共通仕様、受信・保存、ROS 2接続、Web監視、統合と大会運用 | 既存受信経路とログの入出力を確認し、3担当と通信表を作る |
| Main | センサー・校正・品質、推定、FSM、分離・展開、走行とスタック復旧、CAN・TWELITE、撮影・時刻、NVS・Watchdog | 既存センサー単体試験とTest Labの入出力を確認し、着地判断への入力を決める |
| 画像処理 | 校正、左右同期、ステレオ、VO/SLAM、センサー融合、TF、地図・精度評価 | 校正済みサンプル画像で既存ROSパッケージの入出力を確認する |
| Camera | 単眼からステレオ、設定、ID・時刻、CAN、Wi-Fi、バッファ、再接続と計測 | 型番と開発基板を確認し、単眼撮影の単体試験を用意する |
| Drive | 出力・PWM、走行と展開、CAN、有効期限、独立安全停止、再起動と性能評価 | モーター・展開接続をハード班と確定し、出力なしで指令と停止を試す |

Mainは状態遷移時にNVS保存する方針。破損・矛盾・電断からの復帰を扱い、保存状態だけで分離や展開を再実行しない。磁気干渉は駆動時に評価する。Driveは展開未確認・期限切れ・通信途絶時に独立して出力を停止し、再起動後は新しい指令を要求する。Cameraは片側欠損時の再撮影と取得済み画像の再送を区別する。

推奨は物理的な展開完了確認、オフライン再解析、段階的な縮退。高度なWeb再生、速度閉ループや高度な時刻同期は、要否を試験結果から判断する。完成条件は[試験方針](testing_policy.md)。

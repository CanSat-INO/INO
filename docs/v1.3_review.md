# v1.3 開発基盤レビュー

要求の基準は成果物02（INO-SW-ARCH-001）。成果物01は整備範囲、03は共通教材、04〜08は担当別ガイド、09（INO-SW-TEST-OPS-001）は試験と大会運用の参照元。教材中の数値、コード、回路は例として扱う。

| 担当 | 最初の作業 | 入口 |
|---|---|---|
| 班長・地上局 | 既存の受信・保存・表示経路を調査し、CAN・TWELITE・ROS連携の境界をレビュー | #47、#56 |
| Main | 既存FreeRTOS／Test Labでセンサー値の有効性、再生データと実測の違いを確認 | #50、#55 |
| Camera | 基板1枚・左右OV2640候補で、単眼から左右順次取得までの検証表を作る | #48、#51、#54 |
| Drive | 出力を切り離して指令の期限・通信途絶・再起動を検証 | #49、#52 |
| 画像処理 | Lyricalで依存を確認し、録画済み左右画像で校正・視差・点群を検証 | #53、#57 |

従来の計画書のOV5640×2案はOV2640×2候補に更新。基板1枚はMCU台数の確定を意味しない。Jazzyで確認済みの環境やシミュレーターは資産として扱い、Lyricalでの動作は再検証する。既存ESP-NOW/WCPP地上局と新しいTWELITE・ROS 2経路の互換性も確認対象。

班長レビューでは、上記の変更とIF-ERR-01・撮影の保存確認・試験IDの整合を確認する。添付Markdownから参照される図は今回の添付に含まれないため、この資料は設計要点と参照IDを記録する。

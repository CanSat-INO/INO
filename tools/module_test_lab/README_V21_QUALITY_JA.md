# CanSat Module Test Lab v21｜安定化・品質チェック

対象：v20導入済みの INO-module-lab。ESP32-S3実機、地上局、ROS 2、Gazeboへは接続しません。

## 追加した画面
ホーム → 「共通基盤・全体品質チェック（v21）」

- **実験台帳と添付ファイルを点検**：既存の `~/cansat_module_lab_data/records.json` を読み取り、形式・ID重複・添付ファイルの所在・サイズ・SHA256を確認します。変更しません。
- **共有ZIPを点検**：ZIPを展開・インポートせず、records.jsonの形式と添付のSHA256を確認します。v16で出力したZIPに使用できます。
- **インストール構成を点検**：主要なPythonモジュールが存在するかを調べます。
- **サンプルCSVを点検**：v15のBNO055デモCSVを読み取ります。
- **結果をJSON保存**：最後に行った点検のみをJSONに保存します。JSONには添付ファイルの中身やレコード全体は含みません（検出したファイル名は含む場合があります）。

## 既存機能の安全性改善

v20の「作業情報をJSON保存」は、同じフォルダ内に一時ファイルを作成してから置き換える方式にしました。エラーによる途中書き込みの影響を抑えます。シンボリックリンクには保存しません。

## 注意

- 「OK」はファイル整合性に関する判定であり、装置や制御の正常性・安全性を認証するものではありません。
- v20の元コードと異なる独自編集を検出した場合、インストーラーはファイルを上書きせず停止します。
- インストールはプログラムファイルのみで、既存の実験台帳・記録JSON・添付ファイル・IME設定を変更しません。
- 実行前に重要データは別の場所へバックアップすることを推奨します。
- ZIPの「点検」は「別環境での取り込み成功」と同じ意味ではありません。

## 安全に戻す

インストール後に表示されたバックアップフォルダを使います。たとえば

```bash
python3 ~/cansat_v21_install/install_v21.py --repo ~/INO-module-lab \
    --rollback ~/cansat_v21_backups/表示されたバックアップ名 --dry-run
python3 ~/cansat_v21_install/install_v21.py --repo ~/INO-module-lab \
    --rollback ~/cansat_v21_backups/表示されたバックアップ名
```

復元はv21で書き換えたファイルのみで、実験データには触れません。v21適用後にプログラムを編集した場合は上書き保護のため復元を拒否します。

# CanSat Module Test Lab v8.1: Main / CAM / Drive 仮想CAN試験

## 目的

Main・CAM・Driveの仮想メッセージを送受信して、連携・遅延・欠落・拒否・タイムアウトの発生箇所を追跡します。v1〜v7の機能には手を加えません。

**重要**：本機能は論理レベルの模擬試験です。実CAN ID、DLC、バイト列、アービトレーション、バスオフ、電気特性、マイコンの実装、実際のミッション順序については再現・保証しません。試験用プロトコルであり、本番通信仕様ではありません。

## 仮想メッセージ（仮仕様）

| 送信元 | 宛先 | 意味 |
| --- | --- | --- |
| Main | Drive | MOVE（走行開始） |
| Drive | Main | ACK（走行指令に対する応答） |
| Main | CAM | CAPTURE（撮影要求） |
| CAM | Main | ACK（撮影要求に対する応答） |
| Main | Drive | STOP（停止要求） |
| Drive | Main | ACK（停止への応答） |

着地入力を受け取ったときのみ試験用の走行指令を発行します。受信ACKには指令識別番号を付けます。指令が200ms以内に受理されないとMainをFAULTにしてDriveへ停止要求を送ります。これらの数値も**仮の試験ルール**です。電文IDや実機側仕様の確定後に差し替えてください。

## GUIの使い方

1. `3モジュール・仮想CAN` タブを開く。
2. 試験シナリオを選ぶ。
3. `▶ シミュレーション実行` を押す。
4. 送信・受信・欠落・タイムアウト・状態と診断を確認。
5. 必要なら`通信ログをCSV出力`。

テストケース：正常連携 / Drive走行指令欠落 / Drive ACK欠落 / CAM ACK欠落 / CAM ACK遅延 / CAM指令拒否 / Drive停止ACK欠落 / 着地入力なし。

`python -m unittest discover -s tests -v` は `tools/module_test_lab` で実行してください。

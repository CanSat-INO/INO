# v13.1 視認性改善と日本語入力の安定化

## 変更点

- ホーム画面を白いカード・カテゴリ別のアクセント色・アイコン風の記号に整理。
- テキストと背景のコントラストを強め、ボタン・余白を統一。
- 検索欄は入力ごとに即座にカードを作り直さず、350ミリ秒待って絞り込む。
- Qtの日本語IME変換中（preedit）はカードを作り直さず、変換確定後に検索する。
- カテゴリチップをクリックして日本語入力なしでも絞り込み可能（もう一度押すと解除）。
- 既存のタブ・計算・通信・保存・試験ロジックは変更なし。

## 確認方法

1. ホームの色分け・ボタンと検索欄の表示を確認。
2. Windows/WSLで日本語IMEをONにして検索欄に「着地」を入力・変換し、絞り込めるか確認。
3. 上部の「制御・通信」チップを押し、カテゴリが絞り込まれることを確認。
4. 「3モジュール・仮想CAN」などのカードを押し、ページに遷移できることを確認。
5. `~/cansat_gui_venv/bin/python -m unittest discover -s tests -v` で回帰テスト。

### 日本語をまったく入力できない場合

Qtのアプリ以外でも日本語が打てない、または日本語変換ウィンドウが表示されない場合、
アプリ内の検索処理ではなくWSL/X11側のIME構成が原因となる場合があります。
`locale` と `env | grep -E '^(QT_IM_MODULE|XMODIFIERS|GTK_IM_MODULE)='` の結果を確認してください。
ユーザーの環境に応じて ibus / fcitx5 などのQt入力メソッドを設定する必要があります。
この修正版では、IME未設定でもカテゴリチップから目的別に検索できます。

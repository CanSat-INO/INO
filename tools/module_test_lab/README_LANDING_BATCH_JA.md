# Module Test Lab v5 — 着地検知8条件一括試験

## 目的

ハードウェアや実機ログがまだなくても、既存のC++着地判定コードに対して複数の仮想IMU・気圧ログを連続入力して、検知遅延・早期誤検知・未検知・真値なし・入力CSV異常などを確認する機能です。**統合ROS 2シミュレーターとは独立しています。**

## 追加GUI

従来の「C++着地判定」に加え「着地一括テスト」を追加。C++ソースを選択し、「8条件を一括実行」を押します。結果を行で選ぶとグラフを確認できます。「一覧をCSV出力」で表を保存、「各結果を実験記録へ保存」で解析可能な7件をローカル台帳へ追加します。GitHubへの共有は従来の手動方式です。

### ケース一覧

| ケース | ねらい | サンプルロジックで想定される評価 |
|---|---|---|
| 正常着地 | 接地10秒で大きな加速度 | 成功（13秒に判定） |
| センサーノイズ | 加速度値の小さな変動 | 成功 |
| 着地前の衝撃 | 5秒に非着地衝撃 | 失敗（早期誤検知） |
| 弱い着地 | 閾値以下のピーク | 失敗（未検知） |
| 衝撃の遅れ | 実際の接地10秒、衝撃13秒 | 失敗（許容遅延超過。判定時刻は16秒） |
| 着地時の欠損 | 10秒のサンプルを欠落 | 失敗（未検知） |
| 正解時刻なし | 接地真値なし | 未判定 |
| 不正な入力値 | IMU欄に空欄 | 入力エラー |

**「失敗」の件数があるのは意図的な試験条件です。** 今回のサンプルアルゴリズムは実機搭載用の完成品ではなく、特に着地前の衝撃や弱い着地に弱いことを示すものです。

### 現時点の制限

- `cpp_landing_runner.py` のホスト実行APIが受け付ける、ローカルの **信頼できる `.cpp`** に限ります。ESP32-S3固有のライブラリや `.ino` 全体は実行できません。
- C++ソースはコンパイルして**実際にPCで起動されます。** 第三者から受け取った未確認のコードは実行しないでください。現在の実行エンジンはサンドボックスではありません。
- センサーデータは単純な合成波形です。空力・着地衝撃・機体姿勢・BMI270の実測ノイズを忠実に再現したものではありません。
- GUIは各試験を順番に処理するため、実行中は一時的に操作できなくなります。
- ハード班の実測ログ、CAN、構造CAD、ROS 2、GitHub通信は使いません。
- 保存した実験は必ず「外部シミュレーション」として記録され、実機結果にはなりません。

# CanSat Module Test Lab v22 — 目的別ホーム画面

## 変更点
- ホームの上部に「センサーを確認／実験を記録／仮想ミッション／データ比較」の4つの入口を追加。
- 従来の全機能カード・カテゴリ・キーワード検索・IME対応・v20ワークフローの入口は維持。
- 既存の各機能・実験台帳・CSV・JSON・ZIP・起動スクリプトは変更しません。

## 操作
1. `cansat-lab` で起動する。
2. ホーム上部の目的ボタンを選ぶ。既存の機能はその下の一覧から選べます。
3. 画面が狭い場合はホームの一覧をスクロールしてください。

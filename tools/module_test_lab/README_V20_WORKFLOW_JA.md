# CanSat Module Test Lab v20 ― 個別実験ワークフロー

v14.1～v19までの既存機能を削除せず、初めて使う人向けの入口を増やします。

## 使い方

1. ホームの **「はじめての実験：ワークフローを開く（v20）」** をクリック
2. 共通の実験名・担当者・使用機器・コード版を入力。Arduino IDEなどで収集したCSVを選択（実機がなければ同梱BNO055デモCSVを選択）
3. **CSVを確認**：件数・信号数・SHA256を検査（測定精度や合否の保証ではありません）
4. **解析画面へ**：v15にCSVを引き継ぎ、グラフ・統計を確認
5. **実験記録票へ**：v16へ共通4項目とCSVパスを渡し、配線・観測結果・手動判定を確認して保存。別の入力がある場合は置換確認が表示されます。共通4項目とCSV以外の入力・添付コードは残るため、今回の実験に合うか確認してください
6. **ログ比較画面へ**：v19へ測定CSVと任意の参考CSVのパスを引き継ぎ、単位・時間を確認した上で比較

v15/v16/v19の上部で引継ぎ時の共通情報を確認し、「実験ワークスペースへ戻る」でv20に戻れます。解析・比較レポートの既存形式は変えません。

上部の進行表示は、CSV確認・解析への引継ぎ・v16での台帳保存・比較への引継ぎを区別します。引継ぎだけで合否や保存完了にはなりません。台帳保存の表示は、この起動中にv20と一致する共通情報とCSVの保存を確認した場合のみです。共通情報・CSV・データ種別を変更すると進行表示をリセットします。メモだけの変更では台帳保存の表示を維持します。

「作業情報をJSON保存」は台帳とは別の再開用ファイルです。保存後の編集は「未保存の変更あり」と表示されます。CSV選択前の共通情報だけでも保存できます。読込時に未保存の変更があれば置換を確認します。JSON読込ではCSV解析や台帳保存を行わず、進行表示も復元しません。

ホームの4入口は従来どおりです。v20の「その他の既存機能を表示」からv14.1・v17/v18なども開けます。

## データと安全性

- **既存の実験台帳や保存済みデータには変更しません**。
- CSVの送付はローカルファイルのパスを別のタブへ渡す操作で、自動で実験記録を保存しません。
- 実験結果を成功と判断しません。v16への受渡時は「未判定」に設定します。
- v19では単位一致のチェックを外し、再確認を要求します。
- 「作業情報JSON」にはCSV自体を含まず、共通4項目・ファイルパス・SHA256・件数・短いメモが含まれます。担当者名やローカルパスを含むため、共有前に内容を確認してください。
- 新しい作業JSON形式は `cansat-module-lab-workflow-v20-2` です。従来の `v20-1` も読込可能です（共通情報は空欄になります）。新形式を旧アプリで読むことはできません。
- JSONを読み込むだけでは参照先CSVを実行・解析しません。元CSVは別途必要で、SHA256一致を確認してください。
- 外部ネットワーク通信、ROS 2 / Gazebo接続、CAN/TWELITE通信、ESP32-S3ビルドは行いません。
- 本番用C++コードを実行する画面は別途あり、信頼できるコード以外を渡さないでください。

## インストール

v19のソースがあるUbuntu/WSLでインストーラーを実行してください。ドライバや日本語IMEは変更しません。
適用前には対象の `app.py` と `module_navigation.py` のバージョンをSHA256で確認します。
一致しなければユーザーの変更を保護して停止します。

## 実機導入時の注意

センサーCSVの形式と時間単位は計測担当が決める必要があります。シミュレーションの値と実測値が近くても安全性・校正の妥当性は示しません。

## ワークスペース改善のテスト

既存の環境だけで実行できます。GUI試験は一時HOME・一時台帳を使い、実際の台帳・添付を変更しません。Qtの画面部品をオフスクリーンで操作する自動試験です。

```bash
cd ~/INO-module-lab/tools/module_test_lab
python3 -m pytest -q tests/test_v20_workflow_core.py tests/test_v20_workspace_core.py tests/test_v15_sensor_core.py tests/test_v16_experiment_core.py tests/test_v19_compare_core.py tests/test_v21_quality_core.py
~/cansat_gui_venv/bin/python -m unittest discover -s tests -p test_v20_workspace_gui.py -v
python3 v23_release_check.py --repo ~/INO-module-lab
```

GUI試験には既存GUI用venvの `PySide6.QtTest` を使用します。日本語IME・実機・通信の試験ではありません。

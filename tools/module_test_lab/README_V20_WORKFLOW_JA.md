# CanSat Module Test Lab v20 ― 個別実験ワークフロー

v14.1～v19までの既存機能を削除せず、初めて使う人向けの入口を増やします。

## 使い方

1. ホームの **「はじめての実験：ワークフローを開く（v20）」** をクリック
2. Arduino IDEなどで収集したCSVを選択（実機がなければ同梱BNO055デモCSVを選択）
3. **CSVを確認**：件数・信号数・SHA256を検査（測定精度や合否の保証ではありません）
4. **解析画面へ**：v15にCSVを引き継ぎ、グラフ・統計を確認
5. **実験記録票へ**：v16へCSVパスだけ渡し、担当者・実験結果・配線情報を手動入力して保存
6. **ログ比較画面へ**：v19へ測定CSVと任意の参考CSVのパスを引き継ぎ、単位・時間を確認した上で比較

「コードを検証」ではv14.1、「ミッションを試す」ではv17/v18も開けます。

## データと安全性

- **既存の実験台帳や保存済みデータには変更しません**。
- CSVの送付はローカルファイルのパスを別のタブへ渡す操作で、自動で実験記録を保存しません。
- 実験結果を成功と判断しません。v16への受渡時は「未判定」に設定します。
- v19では単位一致のチェックを外し、再確認を要求します。
- 「作業情報JSON」にはCSV自体を含まず、ファイルパス・SHA256・件数・短いメモが含まれます。
- JSONを読み込むだけでは参照先CSVを実行・解析しません。元CSVは別途必要で、SHA256一致を確認してください。
- 外部ネットワーク通信、ROS 2 / Gazebo接続、CAN/TWELITE通信、ESP32-S3ビルドは行いません。
- 本番用C++コードを実行する画面は別途あり、信頼できるコード以外を渡さないでください。

## インストール

v19のソースがあるUbuntu/WSLでインストーラーを実行してください。ドライバや日本語IMEは変更しません。
適用前には対象の `app.py` と `module_navigation.py` のバージョンをSHA256で確認します。
一致しなければユーザーの変更を保護して停止します。

## 実機導入時の注意

センサーCSVの形式と時間単位は計測担当が決める必要があります。シミュレーションの値と実測値が近くても安全性・校正の妥当性は示しません。

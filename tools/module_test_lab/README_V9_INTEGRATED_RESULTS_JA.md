# CanSat Module Test Lab v9 — 統合実験結果・ダッシュボード連携

## 目的
以前の「着地検知・実験記録・チーム共有・結果ダッシュボード」の保存形式をそのまま利用し、v8.1「3モジュール・仮想CAN」、v8.2「C++モジュール連携」、v8.3「異常分析」の実行済み結果も保存・参照できるようにします。

## 使い方
1. v8.4 ホーム/☰メニューから「3モジュール・仮想CAN」「C++モジュール連携」「異常分析」のいずれかに移動し、試験を**実行**します。
2. ホーム/☰メニューから「統合実験結果」を開き、保存対象を選択します。
3. 担当者（任意）を入力し、**現在の結果を台帳に保存**を押します。未実行の試験は保存できません。
4. 保存すると、実験記録・チーム共有と結果ダッシュボードでも確認できます。タイムラインは添付CSVとして保存します。
5. 統合実験結果の一覧では既存の着地記録を含めて、試験種別・成否・キーワードで絞り込み、共有ZIPを出力できます。GitHubへの反映は既存の「実験記録・チーム共有」から**明示的に手動実行**します。

## データ保存と制限
- 保存先は既存の `~/cansat_module_lab_data/records.json` と `attachments/<ID>/module_event_timeline.csv` です。新しい台帳データベースは作りません。
- 既存ダッシュボードの『仮想参考モデル』集計を誤らないよう、保存時の `mode` は `仮想参考モデル` に統一し、詳細な試験方式は `metrics.test_method` と注記に保存します。
- 結果にはシナリオ名、成功/失敗/未判定、Main/CAM/Drive状態、欠落・タイムアウト・C++拒否件数、イベント時系列、分析の発端と波及、利用C++のSHA256（ある場合）が記録されます。
- C++ソースの中身は保存しません。プライベートなディレクトリパスは台帳に追加しません。共有前に自由入力欄と元ログの秘密情報を確認してください。
- **実機のESP32-S3、実CAN、物理的な停止の保証にはなりません。** 全データは仮想試験であると明示されます。
- 着地ログの物理量グラフとCANの通信イベントログは異なるデータです。グラフは混在させず、ダッシュボードでは記録・成否・試験種別で集計します。イベント詳細は統合結果と添付CSVで確認します。
- 保存は明示的操作のみ。重複クリックによる同一実行結果の2重登録をGUI実行中に抑制します。再実行すれば別の実験記録として保存できます。
- **ユーザーの保存済み実験データにはインストール時に手を加えません。** 新しい実験を保存すると既存台帳に追記されます。自動GitHub送信はしません。
- ZIPインポートは既存の`records.py`の検証（ファイル名・ID・SHA256等）を通ります。
- v9では3DシミュレーターやROS 2とは接続しません。

## インストール
作業リポジトリで `main` を最新にし、`feature/integrated-results` ブランチを作成してから、同梱の `install_unified_results.py` を実行します。既存ファイル保護、構造チェック、バックアップ、自動テスト、失敗時の復元を行います。

## テスト
`~/cansat_gui_venv/bin/python -m unittest discover -s tests -v`。GUI起動後は各仮想試験→保存→統合結果/既存台帳/ダッシュボードの順に確認してください。

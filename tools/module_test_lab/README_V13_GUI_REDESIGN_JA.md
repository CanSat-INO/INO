# v13 — カラーGUI / 操作性改善

## 追加した内容

- `gui_theme_v13.py`：アプリ全体に共通する明るい高コントラスト配色、入力欄・表・スクロール・ボタンのデザイン。
- ホーム画面のカテゴリカラー、カテゴリ名、検索対応。各機能ページの上部にも同じカテゴリ名とアクセント色を表示。
- 実行・解析は青、保存・出力は緑、削除・全消去は淡い赤に統一。色だけに頼らず、既存のボタン文言を維持。
- v12の結果一覧で「成功」「失敗」「未判定」の評価セルに淡い背景色を追加。
- 表の見出し・選択行・入力欄のフォーカスを見やすく改善。

## 配色のカテゴリ

| カテゴリ | 色 | 用途 |
|---|---|---|
| 着地・解析 | 青緑 | 着地検知、着地試験 |
| 制御・通信 | 青 | Main/CAM/Drive、仮想CAN、C++連携 |
| カメラ | 紫 | 将来のカメラ機能の表示に対応 |
| 走行 | 緑 | 将来の走行機能の表示に対応 |
| 異常解析 | 橙 | 原因分析、異常追跡 |
| 結果・共有 | 藍色 | 実験履歴、台帳、ダッシュボード |
| 共通基盤 | 水色 | 機体・環境設定 |
| ガイド | 灰青 | 操作案内 |

**注意**：カメラシミュレーションや物理計算はv13では追加しません。カメラの実際の統合はv16の計画です。

## 目視確認のポイント

1. ホームのカードがカテゴリ別の色と名称になっていること。
2. `v12 実験管理・一括比較`で実行ボタンが青、CSV/JSON出力が緑、削除が淡い赤であること。
3. 一括実行後の表の評価欄と選択行が読めること。
4. `3モジュール・仮想CAN`、`異常分析`、`着地検知シミュレーション`など他の機能でも入力、表、ボタンの配色が適用されること。
5. 正常系・異常系の評価やJSON/CSV出力の内容がv12と変わっていないこと。

既存の実験データ、計算式、通信、ROS 2、GitHub同期のロジックは変更しません。

# CanSat Module Test Lab v12 — 実験管理・一括比較

## 目的
v11 の「シミュレーション共通基盤」で作った機体・環境・シナリオ設定を**スナップショットとして複数登録**し、仮想 CAN の論理試験を一括実行・比較・履歴保存します。

v7 の着地パラメータ探索、既存の「着地一括テスト」、v9 の統合実験台帳を置き換えません。今回は **v11 共通形式の仮想 CAN 比較実験に限定**しています。

## 使い方

1. ホームで **「シミュレーション共通基盤」** を開き、機体パラメータとシナリオを設定。
2. ホームで **「v12 実験管理・一括比較」** を開く。「共通設定を開く」ボタンでも戻れます。
3. **「＋ 現在のv11設定を追加」** を押すと、現在の設定のコピーが登録されます。v11 の設定を変えて再度追加すれば複数条件の比較ができます。
4. **「＋ 全8シナリオを追加」** を押すと、機体設定を固定した仮想 CAN 8 シナリオを追加します。
5. 「▶ 一括実行・履歴保存」を押すと、登録条件を上から順に実行し、結果がローカル履歴へ自動保存されます。
6. 実行後、表で条件を選ぶとイベントの時系列を確認できます。「比較CSV出力」「詳細JSON出力」も使えます。
7. アプリを再起動後は、履歴一覧の行を選んで **「選択履歴を表示」** を押すと以前の結果と条件が復元されます。そこから再実行すると新しいIDの別履歴が作られます。
8. 実行前の条件セットをファイルで持ち運ぶ場合は「実験計画JSON保存／読込」を使ってください。

## 比較指標
- 仮想 CAN シナリオ、機体質量、車輪直径、段差高さ
- 評価（成功／失敗／未判定）
- Main、CAM、Drive の最終状態
- メッセージ欠落数、タイムアウト数、イベント件数
- 詳細 JSON には v11 の設定スナップショットとイベント列を保存

## データ・互換性
- 計画JSON: `schema=cansat.experiment.plan`, `version=1`。
- 実行結果JSON: `schema=cansat.experiment.batch`, `version=1`。内部に v11 の `cansat.simulation.run` 形式を含みます。
- 比較CSV: 1条件につき1行。UTF-8 BOM を付けてGUIから出力します。
- 履歴: `~/cansat_module_lab_data/v12_experiment_batches/<実験ID>.json` に新規作成し、同じIDで上書きしません。
- 計画は最大40条件。GUIの自動保存は**実行履歴のみ**であり、未実行の条件は「実験計画JSON保存」で手動保存してください。
- v9の実験台帳とは**別保存**です。ZIPによるチーム共有・GitHubアップロードにも自動連動しません。
- インストーラーは既存ファイル `app.py` をバックアップしてから、v12画面の登録を最小限差し込みます。

## 制限事項（重要）
- **質量・タイヤ径・段差・重心・初期状態は記録のみで、仮想 CAN ロジックの出力に影響しません。** 同一シナリオなら物理パラメータを変更しても同じ論理イベントになります。
- 仮想 CAN は決定論的な参考論理モデルです。表示する成功件数や割合は**実機成功率・通信信頼性・走破率ではありません**。
- 物理運動（位置、姿勢、速度）、ROS 2/Gazebo、REGULUS、カメラ認識実行、ESP32実機、C++ファームウェアの実行連携はv12の対象外です。
- 実行条件はシナリオごとに1回です。ランダム性のある反復試行や統計的信頼区間を提供するものではありません。
- 履歴に個人情報等が入らないよう、共有前に JSON / CSV の内容を確認してください。

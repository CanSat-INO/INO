# CanSat Module Test Lab v3 — 実験結果ダッシュボード

既存のCanSat Module Test Lab v2に、**過去の実験の見える化**を追加した更新です。ROS 2統合シミュレーターとは独立しています。既存のGitHub同期・ZIP共有機能は変更しません。

## できること

- 新しい「結果ダッシュボード」タブで、実験記録を一覧表示
- モジュール・データ種別（参考モデル / 参考モデル以外）・判定・担当者で絞り込み
- 表示中の記録の実験件数、成功・失敗件数、判定済み成功率、参考モデル比率を表示
- 行を選ぶと試験条件、担当者、コード版、結果、実験ID、添付ファイル名を詳細表示
- **保存済みのCSVがある場合のみ**IMU Z加速度と気圧の折れ線グラフを再表示
- 真の接地時刻・検知時刻が記録されていればイベント線を表示（不明なら表示しない）
- 数値が記録済みの着地検知遅延を時系列順に比較
- モジュール別の実験数・成功・失敗・判定済み成功率を表示
- ダッシュボードの「GitHubから取得」から共有記録を読み込み（**クリックしたときだけ同期**）

## Ubuntuで起動

```bash
~/cansat_gui_venv/bin/python ~/INO-module-lab/tools/module_test_lab/app.py
```

新しい「結果ダッシュボード」タブを開き、左の実験一覧から行を選択してください。ログを選んだ実験の詳細グラフは右の「実験の詳細・センサーグラフ」タブです。

「比較・機能別集計」タブでは、**フィルター後の記録だけ**を集計しています。参考モデルと実機を比較したい場合は、データ種別のフィルターで切り替えてください。

## CSVのサポート列

| 項目 | 列名・単位 |
|---|---|
| 時刻 | `time_s` (秒)、または `time_ms` (ミリ秒) |
| IMU Z方向加速度 | `imu_z_mps2` (m/s²) |
| 気圧 | `pressure_pa` (Pa) |
| 検知判定（任意） | `landing_detected` (0/1) |
| 真の接地状態（参考モデル） | `truth_contact` (True/False) |

`time_s` または `time_ms` に加え、加速度・気圧の少なくとも一方が必要です。UTF-8/UTF-8 BOM CSVに対応します。ログは実験記録に添付して保存してください。

- 添付CSVのSHA256が保存時と一致した場合のみグラフ表示します。
- CSVに`landing_detected`があれば、最初に1になった時刻を*CSV由来の検知時刻*として表示します。
- 真の接地時刻は`metrics.true_contact_s`などで**明示的に記録されている場合のみ**表示します。実機ログから勝手に推測しません。
- 実験記録に付いていないCSVはグラフに表示されません。GUIの「実機・外部試験を登録」で添付してください。
- 成功率は「成功÷（成功＋失敗）」で未判定は除外。実機・参考モデルは区別して集計できます。
- 遅延比較は`metrics.delay_s`が保存されている実験のみを対象とします。未登録を0秒扱いしません。

## インストール、データ安全性

`install_v3.sh`は現在のGitブランチが`main`なら実行を拒否します。作業ブランチを作ってから適用してください。

既存の`app.py`はインストール前にSHA256で照合し、一致しなければ上書きしません。変更前のバックアップを`~/cansat_module_lab_v2_backup_日時`へ保存します。

`~/cansat_module_lab_data/` にある記録やログは更新しません。Gitのcommit/push、GitHubへの送信は自動実行しません。

この実装でテストしたのはPythonのデータ処理・既存の同期コードです。実際のUbuntu/WSL上でのGUI描画や手動操作は導入後に確認してください。

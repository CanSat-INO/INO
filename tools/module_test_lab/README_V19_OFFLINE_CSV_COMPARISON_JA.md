# CanSat Module Test Lab v19 — 実験CSV・仮想結果CSV比較

## 役割

実機・ブレッドボードで取得したCSVログと、v17などの仮想/参考CSVを**オフライン**で比較します。ROS 2、Gazebo、地上局通信、Arduino IDE/ESP32コードの実行はありません。

## 操作

1. `cansat-lab` で起動し、ホームの「実験管理・仮想ログ比較（v19）」を開きます。
2. 初回は「比較サンプルをセット」→「同じ物理量・単位」の確認にチェック→「時系列を比較」を押します。
3. 実データが得られたら「実験・測定CSV」を差し替えます。参考側はv17の「時系列CSV保存」の出力CSVなどを指定します。
4. 測定側と参考側の比較したい**信号列**を個別に選択します。単位を確認してチェックします。
5. 時間を調整する必要があれば「参考CSVの時間ずらし」を指定します。プラスの値で参考信号を後ろにシフトします。
6. 「差分CSV保存」「指標・条件JSON保存」でファイルを出力できます。勝手にクラウド送信しません。

## 解析上の注意

- 時刻列（`time_s`, `time_ms`等）は必須です。各CSVの**先頭時刻を0秒**に変換して比較します。実際の同時刻にそろえるには開始時刻や実験イベントで時刻ずらしを調整する必要があります。
- 測定側の時刻で参考値を線形補間します。**重なる時間帯のみ**対象とし、外挿はしません。
- 測定値の欠損は比較対象から除外します。測定側・参考側はともに有効値が2件以上必要です。
- 時刻の重複、逆行、無時間列のCSVは比較できません。
- 指標: MAE（平均絶対誤差）、RMSE（二乗平均平方根誤差）、平均差（測定値−参考値）、最大絶対差、比較点カバレッジ。
- **誤差が小さくても機体性能・物理モデル・実験の正しさを保証しません。** v17は運動物理モデルではなく仮想フェーズモデルです。異なる物理量や単位の比較は禁止してください。
- サンプルCSVは両方とも**架空のデモデータ**です。実際のIMU/GNSSを取得したデータではありません。
- v15 CSVパーサーを利用します。CSVの上限はv15の規定どおりです。

# CanSat Module Test Lab v15：センサー実験・CSVログ解析

## 目的

ブレッドボード上で**別担当者がArduino IDEから取得したセンサーログ**を読み込み、
個別実験の結果を確認するためのオフラインツールです。地上局や統合ROS 2/Gazeboとは独立しています。
新たな実機接続、GPIO操作、Arduinoコンパイル、無線受信、オンライン送信は行いません。

v14.1の着地・Drive・CAM・Main C++ロジック検証、`cansat-lab`の起動、
Fcitx5の日本語入力設定、既存の実験台帳・結果保存は変更しません。

## 使い方

1. `cansat-lab`で起動し「センサー実験・ログ解析」をクリック。
2. 最初は「BNO055 / IMU」を選び「サンプル読込」を押す。
3. 2つの信号を選択してグラフを切り替える。
4. 「基本統計」に有効件数・欠損件数・平均、「データ品質チェック」に時間間隔や値域の注意が出る。
5. 「解析結果をCSV / JSON保存」を押し、レポートを保存する（明示的に押すまで保存しない）。
6. ブレッドボード実験後は「CSVを開く…」から実際の記録を指定する。

**v15の出力は計測ログの検査結果です。故障診断やセンサーの校正・コードの正しさ、実機動作を保証するものではありません。**

## サンプルCSV

`v15_samples/`に以下の架空ログを同梱します。

- `imu_bno055_sample.csv`: 加速度/角速度（50 ms間隔）
- `bme280_sample.csv`: 気圧(Pa)/温度(°C)/湿度/高度
- `gnss_sample.csv`: 緯度/経度/測位状態。GNSS未捕捉時は座標を空欄
- `drive_sample.csv`: PWM/速度/電流/指令（電流と速度は架空データ）
- `camera_sample.csv`: 画像処理**後**の認識値のみ（カメラ画像そのものは解析しない）

このCSVはツール動作確認用であり、実測値や性能証明ではありません。

## CSV形式とヘッダー

- UTF-8（BOM有無どちらでも可）、またはWindows日本語CP932
- 先頭行ヘッダー、以降は同じ列数のレコード
- **時間列は推奨**：`time_s`（秒）、`time_ms`（ミリ秒）または`datetime`（ISO 8601）
- `time_ms` と `time_s` を同時には入れない。時間列がない場合、横軸は**サンプル番号**になる。
- 正式列名に加え、`ax`、`ay`、`az`、`gx`、`gy`、`gz`、`lat`、`lon`、`temp_c`、`pressure_pa`、`pwm`などの別名を自動認識
- 列名不明でも数値だけの列は表示可能（単位は元CSVの記載に従い確認）
- 空欄、`NaN`、`null`等は欠損として扱う。欠損がある線はグラフでつながない場合がある。
- 計測数値に文字列が混入する場合や列数が食い違う場合は読み込みを拒否する。
- 最大12MB、50,000データ行、数値40列の安全上限あり。

CSV例：

```csv
time_ms,accel_x_mps2,accel_y_mps2,accel_z_mps2,gyro_z_dps
0,0.1,0.1,9.8,0.2
50,0.2,0.1,9.9,0.1
100,0.1,0.2,9.7,0.4
```

## 解析・保存の内容

- 単純統計：各数値列の有効件数・欠損件数・最小値・最大値・平均
- 時間列：時間の重複、逆行、中央値を基準にした大きな間隔（欠測候補）
- 座標、湿度、赤占有率の基本値域チェック。観測環境や単位が違う場合は該当チェックの意味を確認
- JSON：統計、品質の注意事項、入力元のSHA256、行数など
- CSV：信号別の統計表、入力元SHA256（元の全数値は複製しない）
- 元CSVは変更しない。ユーザーの操作なしにGitHub・共有フォルダへデータを送信しない。

## 制約・今後の開発

v15は単一ログの可視化と品質チェックまでです。**複数回実験の自動比較、時刻同期、センサーフュージョン、
GNSS地図表示、実機の校正、地上局とのリアルタイム連携、Arduinoコードの実行は対象外**です。
試験結果をチーム全体で管理する作業は既存の「実験記録・チーム共有」を併用します。

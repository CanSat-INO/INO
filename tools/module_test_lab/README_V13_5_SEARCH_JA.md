# CanSat Module Test Lab v13.5 - 関連キーワード検索

v13.4の起動方法 `cansat-lab` と日本語入力（IBUS_USE_PORTAL=1）を**変更せず**、ホーム検索だけを拡張します。

## 機能
- 既存の機能名、カテゴリ名に加え、登録済みの関連キーワードから検索
- 英字は大文字・小文字を区別しない。全角のアルファベット等も正規化
- 複数語はスペース区切りで絞り込み。日本語と英語の連結（`着地CanSat`）も検索可能
- IME変換中の更新待ち（350ms）、固定高カードの描画、タブ切り替えはv13.3のまま

| 入力例 | 関連する画面の例 |
| --- | --- |
| `CanSat` | すべての既存機能（アプリ名として扱う） |
| `GPS` / `GNSS` | 実験記録・チーム共有（GNSS・姿勢モジュールの結果記録） |
| `センサー` / `IMU` | 着地検知シミュレーション、Arduino/CSVログ解析等 |
| `CAN` | 3モジュール・仮想CAN、C++モジュール連携等 |
| `カメラ` / `モーター` | Main・CAM・Drive C++個別試験 |
| `着地 CAN` | 対象語を両方含む関連画面のみ（0件も正常） |

**重要:** キーワード検索は既存画面の案内機能です。新しいGPS測位シミュレーションやセンサードライバは追加されません。

## インストール
1. CanSatアプリを終了し、パッチを展開
2. `python3 install_v13_5.py --repo ~/INO-module-lab --dry-run`
3. 問題なければ `python3 install_v13_5.py --repo ~/INO-module-lab`
4. 通常通り `cansat-lab` で起動

差分は `module_navigation.py` と新規 `navigation_search_v13_5.py`、テスト、説明書のみです。
上書きする `module_navigation.py` はv13.3のオリジナルとハッシュ照合して安全性を確認します。
インストール後のバックアップは `~/cansat_v13_5_backups/<日時>/` に保存されます。

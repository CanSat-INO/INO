# CanSat Module Test Lab v8.2 — PC用C++判断ロジックと3モジュール仮想CANの接続

## 目的
v8.1のMain/CAM/Drive仮想通信試験に、PCでコンパイル可能なC++判断ロジックの結果を差し込みます。v8.1の通常シミュレーションは従来どおり動作します。

### できること
- 「C++モジュール連携」タブで、信頼できる `.cpp` とv8.1の8シナリオを選択
- C++を`g++`でコンパイル、4つの固定判定（Main着地許可、Drive走行許可、CAM撮影許可、Drive停止許可）を取得
- 判定をv8.1論理メッセージシミュレーターに入力
- C++拒否と仮想通信欠落・タイムアウトの違いを、イベントと日本語診断で表示
- ソースSHA256を含む通信イベントCSVを出力
- 既存のv1〜v8.1の画面・動作は維持

### 操作手順
1. GUIの「C++モジュール連携」タブを開きます。
2. `cpp_module/example_module_controller.cpp`で「正常なモジュール連携」を実行します。正常完了するはずです。
3. C++ソースを`cpp_module/example_reject_cam.cpp`に変更して同じ条件を再実行します。`CAM C++拒否`の記録とMainのFAULT状態を確認します。
4. 通常のサンプルに戻し「Drive走行指令の欠落」を実行すると、こちらは**C++拒否ではなく通信欠落・タイムアウト**として記録されます。
5. 「CSV出力」で記録を保存します。

## C++の接続仕様（試験用）

`cpp_module/controller_contract.h` に次の関数を定義しています。

```cpp
extern "C" int cansat_allow_command(int module, int command, int landed);
```

- 返り値: 1=許可、0=拒否、-1=不正な組み合わせ
- モジュール: `CANSAT_MAIN=1`, `CANSAT_CAM=2`, `CANSAT_DRIVE=3`
- 指令: `CANSAT_LANDING=1`, `CANSAT_MOVE=2`, `CANSAT_CAPTURE=3`, `CANSAT_STOP=4`
- v8.2はMain/LANDING、Drive/MOVE、CAM/CAPTURE、Drive/STOPの4種類を判定します。
- `landed`は試験用入力で、現在のサンプルでは1を渡します。
- `stdout`はホストランナー用の通信に使用します。C++コードからデバッグ文字をstdoutに出力しないでください。

本機能は**純粋なC++ロジックを差し替えるアダプター**です。Arduinoの`setup()/loop()`、CANドライバ、センサーライブラリを含む`.ino`全体は直接実行できません。

## 制限事項と注意

- C++で最初に4つの許可/拒否を計算してから仮想CANシミュレーターに反映します。通信途中にC++側の内部状態を逐次更新する本格的な協調シミュレーションではありません。イベント駆動でC++を都度呼ぶ設計は今後の拡張対象です。
- CAN ID、DLC、バイト列、タイムアウト、ミッション順序は**v8.1の仮仕様**です。本番仕様を保証しません。
- 故障時の`Drive=STOPPED`表示も仮想状態です。実機の停止や安全性を保証するものではありません。
- コンパイルとプログラム実行は**サンドボックス化されていません**。チームで作成した、信頼できるC++ファイルだけを選んでください。
- 外部依存ライブラリ、Arduino固有ヘッダー、複数ソースのリンクは現バージョンでは未対応です。`g++`が必要です。
- コンパイル20秒、C++実行3秒でタイムアウトします。現バージョンのGUIは実行中、短時間応答が遅くなる場合があります。
- 試験結果のCSVは自動でGitHubに送信されません。

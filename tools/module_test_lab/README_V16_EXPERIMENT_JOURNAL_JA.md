# v16｜個別実験ノート・コード版・ログ管理

## 目的
ESP32-S3のブレッドボード試験からフェーズ別試験まで、初心者のコード担当者と解析担当者が**同一の実験ID**でログ・コード・配線・観測を残せるようにする補助画面です。v14.1、v15、従来の「実験記録・チーム共有」画面はそのまま残します。

- 課題: 個別試験が進むにつれて「どの配線／どのコード／どのCSVで得た結果か」が分からなくなる
- 解決: 1実験につき1記録。担当者が実験名・開発段階・対象機能・コード版・配線・期待値／観測値／結果を入力
- CSVはv15の読込関数で事前検証（CSVは任意）。Arduinoコードは**保存用の添付のみ**で、コンパイルも実行もしません
- 添付は元ファイルのコピーをローカル台帳に保存しSHA256を付与。履歴からZIP共有／一覧CSV出力
- 保存先は既存の `~/cansat_module_lab_data/records.json` と `attachments`。旧記録の削除・移行を行いません
- 結果「成功／失敗／未判定」は手動入力。CSV品質チェックは故障診断ではありません

## 使い方
1. `cansat-lab` で起動し、ホームの「実験記録・コード版管理（v16）」を開く
2. 「サンプル入力をセット」で模擬ログを使った記録の流れを試せる（勝手に保存はしません）
3. 本番は各実験の「実験名・対象機能・開発段階・担当者・配線・コード版・観測値」を記入
4. Arduinoから保存したCSVを「ログCSV」、スケッチを「コードファイル」に選ぶ（添付は任意）
5. 「CSVを事前確認」してから「実験記録を保存」
6. 実験履歴を検索して記録を選択。詳細を表示し、必要に応じて共有ZIPに出力

## 注意事項
- CSVとコードは各10MB以内。元ファイル自体を変更しません
- 既存の `records.py` を再利用するため、従来の実験記録・結果ダッシュボードにもデータが反映されます。ただし各画面の絞込み方法によっては表示対象が異なります
- ZIPにはコード・CSV・実験メモが含まれることがあります。外部公開前に個人情報・秘密情報を確認してください
- 内蔵のサンプルCSVは架空データです。実機の成功とはみなしません
- これは地上局ではありません。USB・UART受信／ESP32への書込みは行いません
- 変更するのは `app.py` と新規v16モジュールのみ。v13.4の日本語入力と起動設定には触れません

# INØ地上局の開発

既存受信・保存・Web表示を入口に使う。データの受信・保存とWebのライフサイクルを分離し、ROS 2側との接続を rosbridge で検証する。画像・点群の配信は実データ量を計測して決める。ライブ送信機能を持たない再生経路を用意する。

| 画面 | 最初に定義する入力・確認 |
|---|---|
| Overview / System Health | モード、モジュール状態、受信途絶、異常 |
| Navigation / Terrain | 座標系、軌跡、点群、観測範囲、経路 |
| Stereo Camera | Capture ID、左右、取得・受信時刻と欠損 |
| Telemetry / Attitude | センサー値、単位、品質、姿勢 |
| Mission Timeline / Data Explorer | 指令結果、状態・異常履歴、保存データ |

実機・デモ・再生の出所を表示する。大会時はローカルネットワークで運用する。既存の送信・制御画面は確認済みの試験機材でのみ使う。
